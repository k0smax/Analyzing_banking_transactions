# Приложение для анализа транзакций 

Краткое описание: *Приложение позволяет проводить анализ расходов, поступлений, узнавать курсы валют,
цены на акции. Рассчитывать выгоду от использования сервиса Инвесткопилки, а также
анализировать расходы по дням недели за последние три месяца*

## Установка
1. Клонируйте репозиторий:
```
git clone https://github.com/k0smax/Analyzing_banking_transactions.git
```
2. Установите зависимости:

В этом проекте используется инструмент для управления зависимостями и сборкой пакетов в Python - `Poetry`
```
poetry install 
```

## Функционал
Реализованы следующие функциональности:

1 `Страница "События"`
Реализована функция, принимающая на вход строку с датой
и второй необязательный параметр — диапазон данных.

Возвращаемый JSON-ответ содержит следующие данные:
- Расходы
- Поступления
- Курс валют
- Стоимость акций из S&P 500

2 `Сервис "Инвесткопилка"`
Реализована функция, которая возвращает сумму, которую удалось бы отложить в «Инвесткопилку»

3 `Отчет "Траты по дням недели"`
Реализована функция, которая возвращает средние траты в каждый из дней недели
за последние три месяца (от переданной даты)

## Тестирование
